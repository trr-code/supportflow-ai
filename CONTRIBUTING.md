# Contributing

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) with this house style:

- Lowercase type (`feat`, `fix`, `chore`, `ci`, `docs`, `test`, `refactor`)
- Capitalized imperative description
- No trailing period

Examples:

```
feat: Add customer ticket and status workflows
fix: Restore ticket drafts after a refresh
```

After the first public `main` push, use GitHub Flow: short-lived branches, pull request into `main`, merge, delete the branch.
